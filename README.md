# 🎓 Certificate Exhibition

A personal digital portfolio showcasing my professional certificates, academic achievements, completed courses, and continuous learning journey.

## 🌐 Live Demo

🚀 **Explore the website:** [Certificate Exhibition](https://my-certificates-seven.vercel.app/)

## 📖 About

Certificate Exhibition is a personal website designed to organize and showcase my certificates in a clean, modern, and accessible way.

It provides recruiters, employers, and visitors with an easy way to explore my qualifications, skills, and learning achievements.

## ✨ Features

- Organized certificate gallery.
- Certificate previews.
- Easy certificate browsing.
- Fully responsive design.
- Clean and modern user interface.
- Certificate verification links (where available).

## 🛠️ Built With

- React
- Vite
- TypeScript
- Tailwind CSS

## 🎯 Purpose

This project represents my learning journey, professional development, and commitment to continuously improving my skills.
